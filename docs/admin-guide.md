# 관리자 안내

## 역할

행사를 열고, 사람마다 참여 자격을 나눠 주고, 진행을 관리한 뒤 데이터를 지우는 사람입니다. 목표 내용·선물 번호·누가 누구에게 주는지는 관리자 화면에서도 볼 수 없습니다.

## 할 일 (순서대로)

1. `/admin` 로그인 → 행사명, 마감(한국 시각), 예산 저장
2. 참석자 명단 추가 (동명이인은 '민수 A', '민수 B'로 구분)
3. 참여 비밀번호 발급 → 각자에게 **본인 것만** 직접 전달
4. '참여 시작' → 참여 링크 공유
5. 제출 현황 확인. 전원이 확정하면 자동으로 매칭됩니다
6. 마감이 지났는데 미확정자가 있으면: 마감 연장 또는 '미확정자 제외 후 매칭'
7. 행사 당일 이후 '행사 종료' → 원하면 '전체 결과 공개'
8. 종료(또는 공개) 후 **7일 이내** '데이터 삭제'
9. 다음 행사는 삭제 후 '새 행사 준비'

## 주의할 점

- **참여 비밀번호는 발급 직후 한 번만 보입니다.** 창을 닫기 전에 복사하세요. 놓쳤으면 재발급하면 되고, 이전 값은 무효가 됩니다.
- 비밀번호를 단체방에 한꺼번에 올리지 마세요. 남의 것을 알면 그 사람으로 등록할 수 있습니다.
- **매칭 후에는 명단·목표·마감을 바꿀 수 없습니다.** 명단은 매칭 전에 확정하세요.
- 재매칭은 아무도 배정을 확인하지 않았을 때만 됩니다.
- **결과 공개와 데이터 삭제는 되돌릴 수 없습니다.**
- 참여자가 접속 코드를 잃어버리면 '코드 재발급', 내용을 고치고 싶다고 하면 '확정 해제'(매칭 전만 가능)로 처리합니다.
- 4명 미만이면 서로 상대를 쉽게 추측할 수 있습니다.

참여자에게 전달할 내용은 [참여자 안내](participant-guide.md)에 있습니다.
