# 참여자 안내

## 역할

새해 목표를 적어 내고, 배정받은 사람의 목표를 응원하는 선물을 준비합니다.

## 할 일 (순서대로)

1. 참여 링크 접속 → 명단에서 본인 이름 선택 → 주최자에게 받은 **참여 비밀번호** 입력
2. 닉네임(2~20자)과 새해 목표(100자 이내) 작성
3. 화면에 나오는 **접속 코드(16자리)를 복사해 보관**
4. 마감 전에 '확정 제출'
5. 매칭되면 '배정 확인' → 받는 분의 닉네임·목표·선물 번호 확인
6. 예산에 맞춰 선물 준비, 겉면에 **받는 분의 선물 번호** 적기 (내 이름은 적지 않음)
7. 행사 날 **내 선물 번호**가 적힌 선물 찾아가기

## 주의할 점

- **임시저장만으로는 매칭에 포함되지 않습니다.** 마감 전에 반드시 확정 제출하세요.
- **확정하면 닉네임과 목표를 직접 고칠 수 없습니다.** 고치려면 매칭 전에 주최자에게 확정 해제를 요청해야 합니다.
- 접속 코드는 등록 직후 한 번만 보입니다. 잃어버리면 주최자에게 재발급을 요청하세요.
- 번호가 두 개입니다. '받는 분의 번호'는 내가 준비한 선물에 적는 것, '내 번호'는 내가 찾아갈 선물입니다.
- 내 산타가 누구인지는 주최자가 결과를 공개해야 알 수 있습니다.
- 닉네임으로 서로를 알아볼 수 있으니 완전한 익명은 아닙니다. 익명을 원하면 본인을 드러내지 않는 닉네임을 쓰세요.
- 참여 비밀번호와 접속 코드는 다른 사람에게 알려 주지 마세요.
